# Python Scripts

This folder contains the reusable Python scripts for the Global Economic & Development Analytics project.

Planned script categories include:

- World Bank data acquisition and download
- Dataset inspection and indicator coverage analysis
- Data cleaning and preprocessing
- Data validation and quality checks
- Exploratory data analysis
- Agriculture and healthcare indicator analysis
- Chart and visualization generation

## Environment

Install the project dependencies from the repository root:

```bash
pip install -r requirements.txt
```

Run scripts from the repository root where possible so relative data and output paths resolve consistently.
